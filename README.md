# Crypto Course Tests Hub

Статический репозиторий для публикации тестов курса **BlockCapital Crypto Summit** на GitHub Pages.

Что входит:
- статическая платформа из папки `Платформа крипто-курса`;
- верифицированные тесты CS14 в `Платформа крипто-курса/data/lessons/lesson-NN.json` и CS15 в `Платформа крипто-курса/data/cs15/lessons/lesson-NN.json`;
- GitHub Actions workflow для автоматической публикации на GitHub Pages.

Основная рабочая инструкция — в `Платформа крипто-курса/README.md`.

CS15 содержит принятый тест занятия 2: [открыть тест](https://yanlukashin.github.io/crypto-course-tests-hub/?course=cs15&lesson=2). В интерфейсе есть переключатель потоков; прежний корневой адрес открывает CS14. Ответы и результаты двух потоков сохраняются раздельно в браузере ученика.

## Чем отличается от ai-course-tests-hub

В AI-хабе данные парсились из markdown-тестов жёстким парсером. Здесь готовые тесты
пайплайна выходят в разном формате от занятия к занятию, поэтому источник истины —
**верифицированные вручную JSON-файлы** по одному на занятие в папке соответствующего потока. Для CS15 их сверяют с принятыми `05_тест.md` и `05_ключ_теста.md` из учебного комплекта.
Сборщик валидирует их и собирает отдельный `course-data.json` для каждого потока. Сам фронтенд (index.html,
app/main.js, app/styles.css) переиспользован из AI-хаба и формат-агностичен.
